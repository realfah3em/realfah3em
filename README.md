## Selected Practical Coursework

These projects reflect hands-on coursework and learning prototypes, rather than claims of production deployment.

### 1. Bookstore MVC Application

**Java · Spring Boot · Spring MVC · JDBC · MySQL · Thymeleaf**

A basic book-oriented web application used to practise backend structure and database access.

- Organizes request handling, service logic, and DAO-based data access into separate classes.
- Uses `JdbcTemplate` and a row mapper to retrieve book records from MySQL.
- Includes a subject-based book lookup flow and a basic user authentication flow.
- Uses constructor-based dependency injection between application components.

### 2. Books REST API

**Java · Spring Boot · Spring MVC · JDBC · MySQL**

A coursework API for learning how a backend exposes book data over HTTP.

- Practises REST endpoint design for listing, retrieving, creating, updating, and deleting books.
- Uses path variables and request bodies to pass data into controller methods.
- Explores HTTP status responses with `ResponseEntity` and centralised error handling.

### 3. Food Ordering Application

**Node.js · Express · MySQL · React · Redux Toolkit**

A learning application with a React frontend and an Express backend for common food-ordering workflows.

- Includes API routes for signing up and signing in, retrieving the food menu, and managing orders.
- Uses MySQL queries to persist users, food items, and orders.
- Practises password hashing with `bcrypt`, token-based request authorization with JWT, and image uploads with Multer.
- Uses React pages and service modules to call the backend, with Redux Toolkit for cart state.

### 4. E-commerce API Exercises

**Node.js · Express · MySQL**

A modular API exercise organised around user, product, order, and cart routes, with a relational schema for the main entities. It helped me practise splitting an Express application into route modules and connecting server-side code to SQL queries.
